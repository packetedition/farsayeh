# راهنمای پروژه (پایتون + HTML/CSS/JS روی localhost)

بدون Flask و Django. فقط پایتون ۳.۸ به بالا، سه کتابخانهٔ پایتون و یک مرورگر.

## اجرا
```
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
مرورگر خودش باز می‌شود (آدرس: http://127.0.0.1:8765). برای خروج در ترمینال Ctrl+C.
بعد از تغییر در فایل‌های `web/` فقط صفحه را رفرش کن. بعد از تغییر در `main.py` یا `module/` دوباره اجرا کن.

## ساختار
```
main.py          <- فقط import ماژول‌ها و run()
module/          <- منطق پایتون (rose.py، cities.py، demo.py)
web/index.html   <- صفحه (کم و ساده)
web/app.js       <- کد JS تو
web/style.css    <- ظاهر
web/bridge.js    <- ماژول ارتباط سمت وب (لازم نیست دست بزنی)
bridge/          <- ماژول ارتباط سمت پایتون (لازم نیست دست بزنی)
assets/          <- عکس‌هایی که پایتون می‌فرستد
tests/           <- تست‌های پایتون (بدون مرورگر)
requirements.txt <- کتابخانه‌های لازم
cache/           <- کش خودکار پاسخ Open-Meteo
```

## چطور کار می‌کند؟
دو مسیر داریم:

1. **وب ← پایتون**: JS با `py("اسم_تابع", ...)` تابع پایتون را صدا می‌زند.
2. **پایتون ← وب**: پایتون با `show(...)` مقدار می‌فرستد و صفحه **فقط همان مقدارها** را عوض می‌کند.

## ۱) صدا زدن پایتون از JS
پایتون (`main.py`):
```python
@expose
def sum_numbers(numbers):
    total = sum(numbers)
    show(result=total)        # نتیجه را در صفحه بگذار
    return total              # (اختیاری) به JS هم برگردان
```
جاوااسکریپت (`app.js`):
```js
const total = await py("sum_numbers", [1, 2, 3]);
```
- هر تعداد آرگومان بده؛ عدد، متن، لیست، دیکشنری (و عکس به شکل data URL) همه کار می‌کنند.
- هر چه تابع `return` کند به JS می‌رسد (باید قابل تبدیل به JSON باشد).
- اگر تابع خطا بدهد، در ترمینال چاپ می‌شود و در JS یک `Error` پرتاب می‌شود.

## ۲) فرستادن از پایتون به صفحه
در HTML به هر المان یک نام بده:
```html
<h1 data-bind="title"></h1>
<img data-bind="logo">
```
در پایتون:
```python
show(title="سلام")                       # فقط عنوان عوض می‌شود
show(logo=image("assets/logo.png"))      # فقط عکس عوض می‌شود
show(result=5, status="تمام شد")         # این دو تا عوض می‌شوند
```
قواعد:
- روی `<img>` مقدار در `src` می‌رود، روی `<input>` در `value`، روی بقیه به‌صورت متن.
- کلیدهایی که نفرستی دست‌نخورده می‌مانند (مقدارهای قبلی پاک نمی‌شوند).
- آخرین مقدار هر کلید در پایتون نگه داشته می‌شود؛ اگر صفحه را رفرش کنی یا تب جدید باز کنی، دوباره پر می‌شود.
- از هر جای پایتون می‌توانی `show` صدا بزنی (مثلاً وسط یک حلقه برای نمایش پیشرفت کار).

## ۳) عکس
- پایتون ← وب: `image("مسیر.png")` رشته‌ای می‌دهد که به `show` بده.
- وب ← پایتون: در JS و بعد در پایتون:
```js
const url = await fileToDataURL(input.files[0]);
await py("save_photo", url);
```
```python
from bridge import save_image

@expose
def save_photo(data_url):
    save_image(data_url, "assets/uploaded.png")
```

## ۴) پیام دلخواه (اختیاری)
وقتی نمی‌خواهی چیزی در المانی بنشیند و می‌خواهی خودت در JS کاری بکنی:
```python
from bridge import push
push("progress", 40)
```
```js
on("progress", (p) => console.log(p));
```

## نکته‌ها
- پایتون و مرورگر فقط روی `127.0.0.1` حرف می‌زنند؛ از بیرون سیستم قابل‌دسترسی نیست.
- پورت ۸۷۶۵ اگر پر باشد، خودکار پورت بعدی انتخاب می‌شود.
- ارسال عکس‌های خیلی بزرگ (ده‌ها مگابایت) کند می‌شود؛ برای آن‌ها بهتر است عکس را در پوشهٔ `web/` بگذاری و در `show` فقط مسیرش را بدهی (مثلاً `show(logo="photo.jpg")`).

## تب گلباد

تب **گلباد** دادهٔ ساعتی باد را از آرشیو Open-Meteo (مدل ERA5، باد ۱۰ متری) می‌گیرد و
فراوانی جهت و سرعت را برای یک شهر یا مختصات دستی رسم می‌کند.

- شهر را از فهرست شهرهای ایران انتخاب کن و بازه را بده. پیش‌فرض، یک سال کامل است که
  به آخرین روز کامل آرشیو ختم می‌شود.
- برای مختصات دلخواه، بخش «ورود دستی مختصات» را باز کن. نام اختیاری است.
- ارقام فارسی/عربی و جداکنندهٔ اعشار عربی (`٫`) در عرض و طول جغرافیایی پذیرفته می‌شود.
- نتیجه در `assets/windrose/` ذخیره می‌شود: شهرهای آماده با نام
  `<city_id>_<start>_<end>.png` و ورود دستی همیشه در `custom.png`.
- پاسخ خام API برای بازه‌های قدیمی در `cache/` کش می‌شود. این پوشه خودکار ساخته می‌شود.
- اگر پوشش داده کمتر از ۹۰٪ باشد، هشدار فارسی نمایش داده می‌شود.

### توابع پایتون

همهٔ منطق در `module/` است؛ `main.py` فقط ماژول را import می‌کند تا توابع `@expose`
ثبت شوند و بعد `run()` را صدا می‌زند.

| تابع | کار |
| --- | --- |
| `get_cities()` | فهرست شهرها، بازهٔ پیش‌فرض و محدودیت‌های اعتبارسنجی برای ساخت فرم |
| `windrose_city(city_id, start_date, end_date)` | گلباد یک شهر آماده |
| `windrose_custom(name, lat, lon, start_date, end_date)` | گلباد مختصات دستی |

اعتبارسنجی نهایی در پایتون است: عرض `[-90, 90]`، طول `[-180, 180]`، شروع پیش از
پایان، شروع نه پیش از `1940-01-01`، پایان نه بعد از آخرین روز کامل آرشیو، و بازه
حداکثر ۱۰ سال.

### افزودن شهر

در `module/cities.py` یک ردیف به `CITIES` اضافه کن:

```python
{"id": "kish", "name_fa": "کیش", "name_en": "Kish", "lat": 26.5578, "lon": 53.9805},
```

`id` باید یکتا و لاتین باشد؛ از همان لحظه در dropdown صفحه هم دیده می‌شود.
